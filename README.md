# E-Commerce Sales Dashboard – Power BI

## Project Overview

Developed an interactive **E-Commerce Sales Dashboard using Microsoft Power BI** to analyze sales performance, profitability, customer behavior, product performance, payment methods, and regional trends.

The project involved the complete BI workflow, starting from **data import and transformation using Power Query**, followed by **data modeling, DAX calculations, KPI creation, interactive visualizations, filters and slicers**, and finally developing an interactive dashboard to generate meaningful business insights.

---

## 1. Data Source

The project uses an **E-Commerce sales dataset** containing transactional sales information.

The dataset includes information related to:

* **Orders and sales**
* **Customers**
* **Products and categories**
* **Sub-categories**
* **States/regions**
* **Quantity sold**
* **Sales amount**
* **Profit**
* **Payment modes**
* **Order dates**

The raw data was imported into Power BI and prepared for analysis before creating the dashboard.

---

## 2. Import Data in Power BI

* Imported the E-Commerce sales data into **Microsoft Power BI**.
* Connected the dataset to Power BI for analysis and visualization.
* Reviewed the available columns and data types.
* Identified relevant fields required for KPIs, calculations, charts, and dashboard analysis.

---

## 3. Power Query in Power BI

Used **Power Query Editor** for data cleaning and transformation.

### Major activities:

* Checked and corrected **data types**.
* Removed unnecessary or irrelevant columns.
* Handled missing or inconsistent values.
* Renamed columns where required.
* Performed data transformation and formatting.
* Prepared the dataset for analysis and visualization.
* Ensured that numerical fields such as **Sales, Quantity, and Profit** were correctly recognized as numeric values.

Power Query helped convert the raw dataset into a clean and analysis-ready dataset.

---

## 4. DAX in Power BI

Used **DAX (Data Analysis Expressions)** to create calculated measures and perform business calculations.

DAX was used to calculate important KPIs such as:

* Total Sales Amount
* Total Quantity
* Total Profit
* Average Order Value (AOV)
* Monthly Profit
* Category-wise and sub-category-wise performance
* State-wise performance

These calculations allowed the dashboard to dynamically update when users applied filters or slicers.

---

## 5. Measures and Calculations

Created measures to track the overall business performance.

### Important KPIs:

**Total Sales Amount**
Measures the overall sales generated from orders.

**Total Quantity**
Shows the total number of products sold.

**Total Profit**
Measures the overall profit generated from sales.

**Average Order Value (AOV)**
Helps understand the average value generated per order.

These measures were displayed using **KPI cards** on the dashboard for quick performance monitoring.

---

## 6. Charts and Visualizations

Created different Power BI visualizations to analyze the sales data from multiple perspectives.

### Visualizations used:

* **KPI Cards** – Total Sales, Quantity, Profit and AOV
* **Bar Charts** – Sub-category and customer performance
* **Column Charts** – Category and monthly performance
* **Donut/Pie Charts** – Payment mode and category distribution
* **Trend Charts** – Monthly profit/sales trends
* **Geographical/State Analysis** – State-wise sales performance

These visualizations make complex sales data easier to understand and compare.

---

## 7. Filters and Slicers

Added interactive filters and slicers to allow users to dynamically analyze the dashboard.

### Filters/Slicers include:

* **State**
* **Quarter**
* Other relevant dimensions available in the dataset

For example, selecting a particular state or quarter automatically updates the KPIs and charts throughout the dashboard.

---

## 8. Dashboard in Power BI

Created an interactive and user-friendly **E-Commerce Sales Dashboard** by combining KPIs, charts, filters, and slicers into a single report.

### Dashboard highlights:

* Quick overview of overall sales performance
* Profitability analysis
* Product/category performance
* Customer contribution analysis
* Payment mode analysis
* State-wise sales analysis
* Monthly profit trend
* Interactive filtering using slicers
* Easy comparison of different business dimensions

The dashboard provides a centralized view of important business metrics and allows users to explore the data interactively.
