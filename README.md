# E-Commerce Sales Dashboard | Power BI

Developed an interactive **E-Commerce Sales Dashboard using Microsoft Power BI** to analyze sales performance, profitability, customer behavior, product categories, payment methods, and regional sales trends.

The dashboard provides a centralized view of important business KPIs such as **Total Sales Amount, Total Quantity Sold, Average Order Value (AOV), and Total Profit**. It enables users to analyze business performance across different **states, product categories, sub-categories, customers, payment modes, and time periods**.

## Key Features

* Created interactive KPI cards to track **Sales Amount, Quantity, AOV, and Profit**.
* Analyzed **profitability by product sub-category** to identify high-performing products.
* Used **category-wise quantity analysis** to understand product demand.
* Analyzed **payment modes** such as different transaction methods to understand customer payment preferences.
* Created **state-wise sales analysis** to identify regional sales performance.
* Analyzed **customer-wise sales contribution**.
* Created a **monthly profit trend** to identify changes in profitability over time.
* Added interactive **Quarter and State slicers** for dynamic filtering and drill-down analysis.
* Used Power BI visualizations such as **bar charts, column charts, donut charts, KPI cards, and slicers** to present insights in an easy-to-understand format.

## Tools & Technologies

**Microsoft Power BI | Power Query | DAX | Data Cleaning | Data Modeling | Data Visualization | KPI Analysis**

## Outcome

The dashboard converts raw e-commerce transaction data into an interactive business intelligence report, helping users monitor key performance indicators and identify trends in **sales, profit, customer behavior, products, payment methods, and regional performance**.
